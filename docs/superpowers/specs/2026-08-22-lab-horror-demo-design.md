## 1. 개요와 목표

어느 날 퇴근하려던 학부연구생이 뒤틀린 학교에 갇힌다. 잘하면 대학원생으로 확정되고, 못하면 쫓겨나되 학교 밖으로는 나갈 수 없다. "적당히 유능함"을 유지하는 것이 생존 전략이다.

**심사 기준 대응**
- 재밌는 게임 코어 → 낮: "잘해도 위험, 못해도 위험" 줄타기 / 밤: 원잡힘 추격전 (실질 보스전)
- 제약 없는 플레이 → 브라우저 즉시 실행 웹 빌드, 공개 URL, 로그인 없음
- Codex 활용 → 독립 모듈을 Codex에 위임하고 전 과정을 로그로 기록 (12장)

**플레이 타임**: 1회차 10~12분 (추격전 실패 횟수에 따라 변동). 엔딩은 단일 1종 — 데모는 한○○의 결말이 하나뿐임을 전제한다.

## 2. 내러티브 프레임 — "선배의 기록"

- 데모의 주인공은 **한○○** — 풀버전 주인공이 몇 년 뒤 흔적을 발견하게 될 학부연구생 선배 본인. 데모는 풀버전의 프리퀄이다.
- 데모 전체가 **손상된 기록의 재생**이라는 액자 구조. 타이틀 화면부터 "손상된 기록 복원 중…" 연출로 시작하며, 이 연출은 실제 에셋 로딩 진행률과 연동된다 (11장).
- 플레이어는 기록이 남은 파편 구간만 플레이한다. 구간 사이는 **글리치 전환**(화면 흐려짐 + 치지직)으로 건너뛴다 (= 기록이 끊긴 구간). 전환 중 스킵된 시간의 파편이 2~3프레임 스쳐간다 (회식 불판, 시험지, 배양접시, 붉은 비상등).
- 시계는 오프닝의 21:47을 마지막으로 게임 내내 **??:??** 로 표시된다.
- **한○○의 탈출은 실패한다.** 데모의 엔딩은 배드 엔딩 단일 1종 ("기록의 끝", 9장). 풀버전의 TRUE END(퇴근, 아침)는 데모에서 절대 보여주지 않는다.
- **선행자 금지의 범위**: 한○○과 같은 처지였던 *특정 선배 개인*의 흔적·시간 루프 단서는 데모에 넣지 않는다. 제도적 흡수의 암시(졸업생 전원 "대학원 진학"인 명단)는 개인 서사가 아니므로 허용한다.

## 3. 게임 플로우

```
타이틀 — "클릭하여 기록 재생" 게이트(오디오 활성화 겸용) → 복원 연출(클릭 스킵 가능)
         헤드폰 권장 + 조작법 표시
    ▼
오프닝 (조작 시작부터 60~90초, 축약판 허용 — 11장)
  밝은 연구실 → "저 먼저 가보겠습니다" → 복도 뒤틀림
  (조작 시작 30~40초 내 첫 이상: 405호 반복 — 독백 "…또 405호?" + 글리치 스팅으로 오독 방지)
  → 정문 카드 오류 (정신력 -10) → 연구실 복귀 → 교수가 출입증을 걸어줌 → 시계가 ??:??로 깨짐
    ▼ 글리치 전환
[1] 연구실 — 업무 사이클 ① : 서류 처리 미니게임 + 동료 대화
    사이클 종료 시 출입증 강제 노출 1회 (냉동고 리더기가 태그 요구 → 화면에 출입증
    확대 — "학부연구생" 글자가 처음으로 흔들린다)
    ▼ 글리치 전환
[2] 연구실 — 업무 사이클 ② : 샘플 분류 미니게임 + 동료 대화 (이상현상 강도 상승)
    종료 시 모니터에 메시지: "면담실로 오게. — 교수"
    ▼ 글리치 전환
[3] 어두워진 복도 — 추격전 : 목표 = 면담실 도착. 한번 잡히면 게임 오버 → 추격전 재시작
    ▼ 글리치 전환 (최강 — 화면 속에 뭔가 스쳐 지나감)
[4] 면담실 — 엔딩 시네마틱 (조작 없음, 영상 진행)
    일지 몽타주 → 면담 영상 → 기록 끊김 → 엔딩 카드 → 포스트크레딧 → 크레딧
```

- 글리치 전환은 회차가 진행될수록 강해진다.
- 각 페이즈 종료 시 한○○의 일지 1~2줄이 자동 삽입된다 (5장).
- 동선 가이드: 오프닝·연구실은 켜진 형광등 라인과 상호작용 하이라이트로 다음 목적지를 소프트하게 유도한다.

## 4. 스탯 시스템

수치는 화면에 절대 노출하지 않는다. 내부 범위 0~100. 증감치는 **기준값**(플레이테스트로 조정).

**스탯은 엔딩을 분기시키지 않는다** (엔딩은 단일 — 9장). 스탯의 역할은 *과정의 체감*이다: 플레이어의 줄타기가 연출·대사·일지·출입증에 즉각 반영되어, "내 선택이 기록에 남고 있다"를 느끼게 한다.

| 스탯 | 시작 | 역할 (감지 방식) |
|---|---|---|
| 교수 신뢰도 | 50 | 동료·모니터 메시지의 대사 톤 변화 (칭찬 ↔ 경고) |
| 대학원 적합도 | 30 | **출입증** — 직위 글자가 "학부연구생"→"석사과정"으로 잠식되는 정도 (Tab 또는 UI 버튼으로 상시 확인 + 3장의 강제 노출 1회). 높을수록 엔딩 시네마틱의 출입증 잠식이 심하게 표시됨 |
| 정신력 | 100 | 비네트·그레인 강도, 소리 왜곡, 복도 길이 왜곡 |

**스탯 변동 기회**

| 페이즈 | 신뢰도 | 적합도 |
|---|---|---|
| 사이클 ① 서류 | 정확 +5 / 실수 -10 / 행 삭제 들킴 -15 | 정확 +15 / 실수 0 / 행 삭제 -10 |
| 사이클 ① 대화 | — | 호의적 응답 +5 |
| 사이클 ② 분류 | 정확 +5 / 엉망 -15 / 검색 들킴 -10 | 정확 +15 / 고의 오분류 0 |
| 사이클 ② 대화 | — | 호의적 응답 +5 |

- 정신력 감소: 정문 오류 -10, 치아 확대 -10, 폐기물 목소리 -10. 회복 수단 없음. 단계: 70 이상 정상 / 40~69 왜곡 1단계 / 39 이하 왜곡 2단계 + 특수 일지.
- 들킴 이벤트(확률 30%)는 보조 변동일 뿐이며 진행을 막지 않는다.

## 6. 업무 미니게임 2종

3D 씬 위 HTML/CSS 오버레이. 조작은 Pointer Events 기반 커스텀 드래그(HTML5 DnD API 금지), 구현 단순화가 필요하면 "클릭 → 보관/폐기 버튼" 2클릭 방식으로 대체 가능.

### 6-1. 사이클 ① — 서류 처리 "졸업생 진로 현황 업데이트"

랩실 PC. 가짜 스프레드시트에서 졸업생 명단의 빈칸을 채우는 입력 작업.

- 발견 1: 진로란이 **전원 "대학원 진학"** — 빈칸도 예외도 없다.
- 발견 2: **본인 이름이 이미 "대학원 진학 예정자" 명단에 있다.**
- 선택지: 정확히 입력 (신뢰+5 적합+15) / 사소한 실수를 냄 (신뢰-10 적합 변화 없음) / 본인 행을 조용히 삭제 (적합-10, 30% 확률로 들켜 신뢰-15)
- "정확히 입력"을 골라도 즉시 반응 비트가 붙는다: 동료 — "교수님이 너 마음에 들어하시더라." + 출입증 아이콘 1프레임 글리치. ("잘함→끌려감"의 인과를 모든 플레이 스타일에게 노출)

### 6-2. 사이클 ② — 샘플 분류 "조직 샘플 정리"

냉동고 앞. 샘플 튜브를 라벨 대조 → 보관/폐기 판정 (6~8개).

- **분류 정확도가 스탯에 반영된다**: 오류 0~1개 = 정확 (신뢰+5 적합+15) / 오류 2~3개 = 적당 (변화 없음) / 오류 4개 이상 = 엉망·고의 오분류 (신뢰-15 적합 0). — 사이클 ①의 줄타기 딜레마가 여기서 변주·반복된다.
- 이상 요소 (공포 축, 스탯과 독립): 샘플 하나에 작은 **치아** (확대 가능, 확대 시 정신력-10). 치아 샘플의 라벨 지시는 "보관"이며, 폐기로 분류하면 오류로 집계되고 특수 일지가 붙는다. 폐기물통에서 "톡, 톡" 소리 → 접근하면 "선배님." 목소리 (정신력-10).
- 부가 선택지: 동료에게 질문 ("그거 원래 그래.") / 몰래 기록 검색 (일지 단서, 30% 확률로 들켜 신뢰-10)

## 7. 동료 대화

- 사이클 ①의 동료 1인은 **동선상 자연 발생** (자리로 가는 길에 말을 걸어옴) — 최소 힌트 1개("교수님이 너 얘기 하더라")는 전 플레이어에게 보장. 나머지 대화는 선택 사항.
- 각 사이클 대화의 호의적 응답은 적합도 +5 ("랩 생활 재밌어요" 류). 심드렁한 응답은 변화 없음.
- 기능: 스탯 힌트, 이상현상에 대한 무심한 반응 ("밖이 뭐?"), 세계관 전달.
- 동료는 얼굴 없는 로우폴리 실루엣.

## 8. 추격전 — 어두워진 복도 (실질 보스전)

- **목표: 면담실 도착** (교수 호출이 3장에서 선행). 405호 반복, 잘못된 문은 원위치로 리다이렉트 (오프닝 왜곡 로직 재사용).
- **한번 잡히면 게임 오버.** 짧은 포획 연출(화면 급속 치지직 + 암전) → "기록 손상 — 해당 구간을 재복원합니다" → 추격전 시작 지점에서 재시작. 낮 파트의 스탯·일지는 유지된다 (되돌리지 않음).
- **난이도 자동 완화 (막힘 방지)**: 실패가 누적될 때마다 몰래 완화한다 — 2회째부터 추적자 감지 반경 -20%씩, 4회째부터 이동 속도도 -10%씩 (하한 있음). 화면에는 절대 표시하지 않는다. 최악 케이스에도 수 분 내 통과 가능해야 한다.
- 추적자는 전신을 보여주지 않는다: 발소리, 형광등이 차례로 꺼지는 방향, 모퉁이 실루엣, 관 끌리는 소리. 근접 시 화면 치지직 + 심장소리 (거리 = 강도, 소리 없이도 시각 신호로 성립).
- 코어 메커니즘: 달리면 발소리로 위치 노출 / 걸으면 조용함 + 시야 회피. **사물함·강의실 숨기는 1차 컷 후보** — 코어 완성 후 여유 시에만 추가.
- 추격전 실패 경험은 일지에 반영된다 (5장).
- 추적자 AI: 웨이포인트 그래프 상태머신 (순찰 → 소리 감지 → 추적 → 시야 상실 시 배회 → 복귀). 내비메시 불필요.
- 비유클리드 구현 규칙: 텔레포트·세그먼트 재배치는 반드시 시야가 가려진 순간(문 통과 프레임, 글리치 플래시)이나 카메라 프러스텀 밖에서만 수행. 포털 렌더링 등 고급 기법은 배제.

## 9. 엔딩 시네마틱 — "기록의 끝" (단일, 조작 없음)

면담실 도착과 함께 조작이 끝나고 영상이 진행된다. 분기 없음.

**시퀀스 (고정)**

1. **일지 몽타주** — 이번 판에 쌓인 일지 문장들이 어두운 화면 위로 스크롤 (판마다 내용이 다름 — 줄타기 플레이의 회고 보상).
2. **면담 영상** — 면담실. 교수는 얼굴 없는 실루엣, 비정상적으로 긴 침묵과 정지된 자세 (표정 애니메이션 없음 — 스코프 아웃). 교수의 질문은 들린다: "요즘 연구는 어때?" / "그런데 왜 우리 연구실에 들어왔어?" — 그러나 **한○○의 대답은 전부 치지직으로 손상되어 들리지 않는다.** 기록은 학교가 남긴 것이므로. 적합도가 높았던 판일수록 화면 속 출입증의 "석사과정" 잠식이 심하게 표시된다 (연출 반영, 분기 아님).
3. **기록 끊김** — 교수: "……그래." → 한○○이 면담실을 나선다 → 정문 → "퇴실 요청이 접수되었습니다." → (글리치) → **"진학 처리되었습니다."** — 탈출을 요청한 사람에게 학교가 진학으로 응답한다 → 화면이 격렬히 치지직거리며 기록이 끊긴다. 아침은 나오지 않는다.
4. **1.5초 정적** → "이후의 기록은 복원할 수 없습니다."
5. **엔딩 타이틀 카드** — "기록의 끝" (크래시 오해 방지 — 의도된 엔딩임을 즉시 증명).
6. **포스트크레딧 (고정 컷)** — 몇 년 뒤. 새 학부연구생이 명단을 정리하다 멈춘다 — **"한○○ · 진로 확인 필요"** → 치지직 → 끝. (본편 예고. 학교는 한○○을 서류상 졸업 처리했고 진로만 미확인으로 남았다 — 명단 등재의 근거.)
7. 크레딧 (에셋 라이선스 표기 포함) → 타이틀 복귀.

## 10. 연출 원칙

1. 연구실은 항상 밝고 생활감 있게. 공포의 기본은 "정상처럼 보이는 곳의 이상함".
2. 점프스케어 대신 반복·모순·잘못된 기록·NPC의 무심함. 추격전의 긴장은 소리와 빛으로.
3. 첫 이상현상(405호 반복)은 **오프닝 조작 시작 후 30~40초**에 온다. 반복은 오독 불가능하게: 독백 "…또 405호?" + 글리치 스팅 + 문패 중앙 카메라 유도.
4. 시계는 ??:?? 고정. 글리치 전환은 갈수록 강해진다.
5. 괴물의 전신은 끝까지 보여주지 않는다.
6. 헤드폰 권장 문구 + 소리 없이도 플레이 가능 (시각 병행).

## 11. 기술 아키텍처

**스택**: Three.js + Vite + TypeScript (엔진 없음).

**지원 범위**: Chrome/Edge 최신 데스크톱 = 1급 (60fps 목표). Safari/Firefox = 실행 확인 수준. 모바일·터치 = **스코프 아웃** — UA/터치 감지 시 게임 분위기의 정적 안내 화면 ("이 기록은 데스크톱 + 키보드 + 헤드폰 환경에서만 복원됩니다").

**성능 정책**
- 라이팅: **실시간 그림자 전면 배제.** 앰비언트+헤미스피어 + 씬당 포인트/스팟 2~3개 상한. 천장 형광등은 emissive 재질. 추격전 복도는 안개 + emissive 비상등만. (베이킹 파이프라인 학습 비용 제거)
- 포스트프로세싱: 비네트·그레인·글리치·RGB 시프트를 **uniform 강도 파라미터를 받는 단일 커스텀 셰이더 패스 하나로 통합**. `setPixelRatio(min(devicePixelRatio, 1.5))`. AA는 FXAA 또는 생략. 글리치 전환·정신력 왜곡·추적자 근접 경고 전부 이 패스의 파라미터로 구현.
- 로딩: 초기 번들(코드+타이틀 에셋) 1MB 이하로 **타이틀 표시까지 3초**. "손상된 기록 복원 중… N%"는 실제 프리로더 진행률과 연동(디제시스 로딩). 씬별 에셋은 글리치 전환 중 백그라운드 로드. 전체 빌드 ~15MB 이하.

**입력/모드 관리 (1주차 스파이크 1순위)**
- FPS 모드 ↔ UI 모드 상태머신: 오버레이 열릴 때 `exitPointerLock()` + 커서 표시, 닫을 때 "클릭하여 계속" 제스처로 재잠금. `pointerlockchange`를 단일 진입점으로 처리.
- Esc는 가로챌 수 없다 → **Esc = 일시정지 메뉴**로 편입. Tab은 잠금 중 `preventDefault`, UI 모드 중엔 화면 버튼 병행.
- PointerLock 요청 실패 감지 시 안내 문구 (iframe 임베드 대비). 페이지 최상단에 "새 창에서 열기" 상시 노출.
- 키: WASD 이동, 마우스 시점, E 상호작용, Shift 달리기, Tab 출입증.

**오디오**
- 타이틀 "클릭하여 기록 재생" 게이트에서 `AudioContext.resume()` (자동재생 정책 대응).
- 포맷: **MP3 또는 AAC(m4a)로 통일** (Safari OGG 미지원). Web Audio 거리 감쇠. 형광등 험, 발소리, 심장소리, 글리치 노이즈 (Freesound CC0).

**씬 구성**

| 씬 | 내용 | 핵심 기술 |
|---|---|---|
| 타이틀 | 오디오 게이트, 복원 연출(=프리로더), 조작법 | 글리치 셰이더 |
| 오프닝 | 독립 공수로 견적. 축약판 사전 정의: 복도 왜곡 1회 + 카드 오류 + 암전·자막으로 압축 가능. 출입증 수령은 암전+사운드+텍스트로 대체 가능 | 스크립트 시퀀서 |
| 연구실 | 업무 사이클 ①② | 밝은 형광등(emissive), 상호작용 오브젝트 |
| 복도 | 오프닝 왜곡 + 추격전 (공유) | 모듈식 세그먼트 반복, 웨이포인트 AI, 가림-순간 텔레포트 |
| 엔딩 | 면담실 시네마틱 + 일지 몽타주 + 포스트크레딧 (단일 시퀀서 씬으로 통합) | 연출 시퀀서 |

**상태 관리**
- 단일 GameState 객체 (스탯 3종, 플래그, 일지 배열, 추격 실패 횟수).
- **자동 체크포인트**: 페이즈 경계(글리치 전환 시점)마다 sessionStorage 직렬화. 재접속 시 "기록을 이어서 복원하시겠습니까?" 1줄. (F5·이탈 사고 방어. 추격전 게임 오버 재시작도 이 체크포인트를 사용)

**에셋**
- 모델 GLB (저폴리, Draco 불필요) — Kenney/Quaternius CC0 + 단순 지오메트리 직접 제작. 텍스처 WebP/JPG.
- 인물: 얼굴 없는 로우폴리 실루엣 (교수 포함 — 표정 애니메이션 스코프 아웃).
- 한글 폰트: 사용 글자 서브셋 woff2 (풀셋 1~2MB 금지).
- 라이선스 표기를 크레딧에 포함.

**데모 컷 라인 (일정 압박 시 버리는 순서 — 각 단계가 그 자체로 제출 가능)**
1. 관통 슬라이스: 연구실 + 미니게임① + 엔딩 시네마틱 축약판 (처음부터 끝까지 플레이 가능)
2. 추격전 (게임 오버·완화 규칙 포함)
3. 미니게임② + 동료 대화 + 일지 몽타주
4. 오프닝 연출 강화, 숨기 메커니즘, 파편 플래시, 폴리시

## 12. Codex 활용 계획 (가산점 대응)

**원칙: 사람이 인터페이스(uniform 목록, 상태머신 입출력, 함수 시그니처)를 먼저 확정한 뒤 위임한다.** (설계 결정과 얽힌 모듈을 결정 전에 위임하면 재작업이 된다)

위임 후보 6건 (성공 기준은 4건 이상 — 15장):
1. 추적자 AI 상태머신 (순찰/감지/추적/배회 + 실패 누적 완화 파라미터)
2. 복도 왜곡 생성 로직 (세그먼트 반복·문 리다이렉트)
3. 글리치 포스트프로세싱 셰이더 (통합 패스 설계 확정 후)
4. 미니게임 UI 로직 중 1종
5. 일지/자막·엔딩 시퀀서
6. 사운드 매니저 (로딩·거리 감쇠·페이드)

모든 세션을 `docs/codex-log.md`에 기록: 날짜 / 맡긴 작업 / 프롬프트 요지 / 결과 / 사람이 수정·결정한 부분.

## 13. 배포와 제출물

- GitHub Pages + GitHub Actions (빌드 → deploy-pages). **1주차에 배포 파이프라인부터 세팅 — "배포 먼저, 개발은 배포된 상태 위에서".**
- `vite.config.ts`에 `base: './'` 필수 (프로젝트 페이지 하위 경로 404 함정). 에셋·오디오 경로 상대 경로 통일.
- 제출 형식이 직접 링크인지 임베드인지 사전 확인 (체크리스트). 임베드 대비책은 11장 입력 관리 참조.
- 제출물: 플레이 링크 (필수) / 3분 데모 영상 (가산점) / Codex 활용 설명 (가산점).
- **데모 영상 방침**: 시간순 요약이 아니라 하이라이트 우선 구성 — 추격전, 출입증 잠식, 엔딩 시네마틱의 기록 끊김을 앞세운다. 라이브 플레이가 못 닿는 뒷부분을 영상이 보증한다.

## 14. 스코프 아웃 (풀버전 유보)

시험·학점, 회식, 랩미팅/발표, 정전 이벤트(추격전으로 대체), 취업 등 진로 확정 루트·탈출 근거 스탯, 엔딩 10종 체계(데모는 단일 엔딩), 교수 면담 선택지 보스전(데모는 시네마틱), 수동 세이브/로드, NPC 외형 왜곡 세부 단계, 3D 표정 애니메이션, 모바일/터치, 다국어. — 글리치 전환의 파편 플래시로만 존재를 암시한다.

## 15. 성공 기준

1. 심사위원이 링크 접속 → 타이틀 표시 3초 내 → **오프닝 조작 시작 후 40초 내 첫 이상현상**.
2. 1회차 10~12분에 엔딩 도달. 어떤 선택·플레이로도 막히는 구간 없음 (추격전은 실패 누적 자동 완화로 상한 보장).
3. "잘해야 하나 못해야 하나" 고민이 최소 2회 발생 — 사이클 ①과 ② 모두에 줄타기 선택이 있고, 그 결과가 일지·출입증·대사로 즉시 되돌아옴.
4. Chrome 기준 중사양 노트북(내장 GPU)에서 60fps — 마일스톤마다 실측.
5. 추격전 게임 오버 후 재시작이 3초 내에 이뤄지고 낮 파트 진행은 보존됨.
6. Codex 로그에 실질 작업 4건 이상 기록 (후보 6건 중).
